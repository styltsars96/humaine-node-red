Evaluation Config Node

Performs CRUD operations on HAIC Evaluation Configurations.

Operations

  • get - Retrieve a configuration by ID. Requires: payload.id
  • create - Create a new evaluation config body. Payload becomes request body.
  • update - Update an existing config. Requires: payload.configurationId
  • delete - Delete a config by ID. Requires: payload.id

Input Payload Examples

{ "operation": "get", "id": 1 }
{ "operation": "create" /*, ...config fields */}
